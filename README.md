## Deskripsi
Project ini dibuat untuk memenuhi tugas Praktikum 5 mata kuliah Pemrograman Web. Project berisi latihan dasar JavaScript dan manipulasi elemen HTML.

## Tujuan Praktikum
1. Memahami penggunaan JavaScript pada HTML.
2. Memahami variabel, fungsi, dan kondisi.
3. Menggunakan operasi aritmetika.
4. Memeriksa nilai dan bilangan genap atau ganjil.
5. Mengubah warna background halaman.
6. Menghitung total harga menu.
7. Membuat kalkulator nilai mahasiswa.

## Daftar Latihan
- Latihan 1: Hello World
- Latihan 2: Input Nama
- Latihan 3: Operasi Aritmetika
- Latihan 4: If Else
- Latihan 5: Switch Case
- Latihan 6: Genap atau Ganjil
- Latihan 7: Mengubah Warna Background
- Latihan 8: Menghitung Total Menu
- Mini Project: Kalkulator Nilai Mahasiswa
- Eksperimen Mandiri: Prompt, tabel perkalian, dan validasi input

## Struktur File
- `index.html` — Struktur halaman web.
- `script.js` — Kode JavaScript untuk menjalankan latihan.
- `README.md` — Dokumentasi project.
- `screenshot/` — Dokumentasi screenshot coding dan hasil program.

## Cara Menjalankan
1. Buka folder project menggunakan Visual Studio Code.
2. Buka file `index.html`.
3. Jalankan menggunakan Live Server.
4. Klik tombol pada halaman untuk mencoba setiap latihan.
